# ReservaYa

Aplicación móvil para reserva de servicios.

## Instalación

1. Instalar dependencias:

   ```bash
   npm install
   ```

2. Iniciar la aplicación:

   ```bash
   npx expo start
   ```

   Luego escanea el código QR con Expo Go o abre el emulador que prefieras.

## Recursos

- Código fuente en `/App.js`
- Assets en `/assets/images/`
